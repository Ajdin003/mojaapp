# MojaApp – RS1 vježbe 1

Početni ASP.NET Core Web API (.NET 8) s kontrolerom `StudentiController`. Podaci se čuvaju u memoriji (`StudentStorage`).

Pokretanje: otvorite `MojaApp.sln` u Visual Studiju i pokrenite projekat `MojaApp.API` (F5), ili iz komandne linije:

    dotnet run --project MojaApp.API --launch-profile http

Swagger: http://localhost:5183/swagger. Gotovi zahtjevi za testiranje su u `MojaApp.API/MojaApp.API.http`.
